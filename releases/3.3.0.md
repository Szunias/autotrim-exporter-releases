# AutoTrim Exporter 3.3.0

AutoTrim Exporter 3.3.0 turns the export step into a complete delivery: the
files leave REAPER already named, tagged, measured and checked. Rendering engine
2.10.0.

This release also carries everything from the unpublished 3.2.0 — trimming can
be switched off, the number of render passes is yours to choose, and several
cases where the exporter removed audio you wanted to keep are fixed. If you are
coming from 3.1.1, read the 3.2.0 notes as well.

## New

- **UCS 8.2.1 naming.** Deliver canonical filenames —
  `CatID_FXName_CreatorID_SourceID_UserData` — built from an embedded copy of
  the published category list. No download, no external file. Field order and
  separator are yours to set. An unknown CatID warns and is used exactly as you
  typed it; an empty one keeps your regular name. Naming never blocks an export.
- **Metadata written into the files.** iXML USER fields that Soundminer and
  BaseHead read, plus BWF and ASWG, are embedded during the delivery render —
  including the loudness AutoTrim already measured. No more re-tagging every
  file by hand after export.
- **Delivery profiles.** Eight built-ins carrying the published numbers — Game /
  Wwise, Unreal Engine, EBU R128, ATSC A/85, Netflix, streaming music, podcast,
  library master — plus your own saved profiles. A profile sets format, sample
  rate, bit depth, channel policy, loudness target, ceiling and tolerance in one
  click. Unreal's 16-bit conversion and Netflix's dialog-gating caveat are
  stated on the profile rather than hidden in a manual.
- **Bit depth, RF64 and channel policy** for WAV deliveries. Your other WAV
  settings, including the BWF chunk, are preserved.
- **Delivery report.** Every batch writes `_DeliveryReport.csv` and
  `_DeliveryReport.html` next to the files: format facts, LUFS-I, LRA, true
  peak, and a verdict per file against the target you declared. It also catches
  what people usually catch by ear on release day — silent files, DC offset,
  duplicate names and hard edges where a fade was requested. It can be switched
  off when you want the speed.
- **A Delivery page** in the interface (key `4`) for all of the above.

## Fixed

- A missing ReaImGui no longer ends the script — the classic window is offered
  instead, with the same engine and the same settings.
- The history no longer prints a bare `N/A`: a missing measurement says what is
  missing and why.
- Per-item exports say up front how many MIDI or take-less items will be
  skipped, and offer the combined render instead of dropping them at render
  time.

## What this report does not claim

- Loudness figures are ungated BS.1770 measurements. Dialog-gated
  specifications, Netflix among them, must be verified in a dedicated meter.
- Leq(m), used by trailer standards, is not measured.
- True-peak values reuse REAPER's own measurement within a small reporting
  grace.

## Requirements

- REAPER 7 (64-bit)
- ReaImGui 0.10.0.5 or newer in the 0.10 API series
- SWS is optional; without it, loudness and bit depth read as "not measured"
- Windows, macOS, or Linux

## Upgrading

Install over the previous version and re-register only the packaged launcher.
Your settings are preserved, and every new feature is off by default: naming,
metadata and profiles do nothing until you switch them on. There is no public
3.1.2, 3.1.3 or 3.2.0 — 3.3.0 follows 3.1.1.

The release download contains the product, Inter font license, installation
instructions, a machine-readable manifest, and a separate SHA-256 checksum.
