# AutoTrim Exporter 3.5.0

One new feature on top of 3.4.5: a third render mode that delivers marked
groups in the order you marked them, numbered automatically. The rendering
engine is unchanged at 2.11.6, so every delivery fix from 3.4.5 applies here
too — if you are upgrading from 3.4.4 or earlier, read the
[3.4.5 notes](3.4.5.md) as well.

## New: Queue mode

**Mark one sound, mark the next, mark the next — then export once and get
`Name_01`, `Name_02`, `Name_03`.**

Numbering a batch of variations used to mean retyping the delivery name between
every export: type `Impact_1`, export, type `Impact_2`, export. Worse, the
automatic collision suffix then fought your manual number, so a re-export
produced names like `Impact_1_002.wav` — two numbering schemes in one filename.

Queue mode sits next to Per item and Combined render on the Export page:

1. Select the layers of a sound (`V` still collects overlapping items).
2. Press **`Q`**, or click **Add group**. The panel shows `01 · Impact_layers · 4 items`.
3. Select the next sound, press `Q` again.
4. Export once. Each group is delivered as its own file, numbered by its
   position in the queue.

Each group renders exactly the way Combined render does, so trimming,
normalization, fades, metadata, UCS naming, the delivery report and Undo all
behave as they always have — one complete export per group.

### Working with the queue

- **Click a row** to select that group in REAPER. This is how you check what
  group 2 actually is before committing to the order. It only changes the
  selection, so it never modifies your project.
- **Reorder** with the arrows, **remove** a single group, or **clear** the queue.
  The numbering follows the panel, so moving a group renumbers its delivery.
- **Colour groups in the arrange** is an optional checkbox, off by default. It
  tints each group in its own colour so you can see the whole queue on the
  timeline at a glance. It does write item colours in your project — the
  original colours are captured before tinting and restored when a group leaves
  the queue or the queue is cleared, but the project will register as edited.
- **The name field still drives the base name.** Leave it empty and each group
  falls back to its own take name, so a queue of unrelated sounds does not
  collapse onto one numbered series.

### What happens when things change under you

If you delete items after marking them, those groups are dropped before
numbering, so the delivered files still run `01` through `N` with no gaps — and
the panel and status line tell you how many were skipped rather than quietly
absorbing them. Whatever you typed in the name field is restored after the run,
including when an export fails or you cancel it.

The queue lives as long as the AutoTrim window and your project stay open. It is
deliberately not saved between sessions: a remembered queue whose items have
moved on would be worse than rebuilding it, which takes a few keystrokes.

## Upgrading

Replace the installed scripts with the ones in this package. Your settings,
delivery profiles, name lists and export history are stored by REAPER and carry
over untouched.
