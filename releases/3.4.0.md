# AutoTrim Exporter 3.4.0

AutoTrim Exporter 3.4.0 adds the check that was missing at both ends of an
export: what the render will pass through before it runs, and how to take a
delivery back after it has run. The interface was rebuilt around the window,
the progress display and the navigation. Rendering engine 2.11.0.

This release also carries everything from the unpublished 3.2.0 and 3.3.0 —
optional trimming and a chosen number of render passes, UCS naming, embedded
metadata, delivery profiles, WAV bit depth and channel policy, and the delivery
report. If you are coming from 3.1.1, read those notes as well.

## New

- **Preflight (key `6`).** Reports what a render will actually pass through,
  before it runs. Findings depend on the mode you are in: a combined render is
  taken from the master, so a muted master, an offline master effect or a solo
  that silences exported material will make the file wrong and are reported as
  blockers. A per-item render never touches the master, so the same chain is
  reported as skipped instead. Monitoring FX are flagged in both modes, because
  they reach your speakers and never the file. Every finding states the fact and
  what it means for the delivered file.
- **An opt-in one-click fix** for the two problems that can be reversed with
  confidence: a muted master and a Bypass automation override. Off by default,
  offered only for a combined render, applied only while that render runs and
  restored on every exit path including a cancelled or failed one. A solo or an
  offline plugin is reported and never touched.
- **Undo the last delivery.** Off by default. With *Keep backups to undo
  replacements* on, every file a replace-mode delivery overwrites is copied
  aside before the swap, and one export is one undoable batch. An undo tells you
  what it could not restore rather than claiming success, and files that were
  newly created are left alone — removing them would delete work nobody
  overwrote. The ten most recent batches are kept, and backups older than a week
  are pruned.
- **Boundary preview with audition** on the Trim & fades page. See where the
  trim will land before spending a render: the preview uses the delivery's own
  arithmetic, on demand, with no render pass. Audition plays between those
  bounds and puts the edit cursor back afterwards. A silent item reports the
  noise floor it measured instead of drawing invented boundaries.
- **A resizable window that remembers its size,** with the normal system resize
  grip and no upper limit. Narrow the window and the sidebar becomes a tab bar
  and the page scrolls, instead of content sliding off the edge.
- **A progress display worth reading.** It names the stage — prepare, analyze,
  render, verify, finish — with the file in hand, its position in the batch, the
  percentage of the whole job, the elapsed time and whether cancelling is safe
  right now.
- **The action is a toggle.** Running it a second time closes the window instead
  of opening another copy. Your settings and history are kept.

## Fixed

- **A file too short to measure is no longer failed on loudness.** Integrated
  loudness is undefined below 400 ms and Loudness Range is not recommended below
  a minute, yet both were judged against your tolerance regardless of length — a
  short, correct delivery could be handed a FAIL on a number that does not
  physically exist. Both are now reported as unjudged below their threshold,
  with the reason stated. Above it, the same deviation still fails.
- **The export summary previewed a filename that would never be written.** With
  UCS naming on, the preview is now produced by the same function that names the
  file.
- **Large sessions stay responsive.** Settings reach disk once, shortly after
  your last change, rather than on every click; the selection is fully rescanned
  only when it actually changed; and the History page draws the newest hundred
  rows and says how many more it is holding.
- **Interface panels close correctly even when clipped out of view,** which is
  what caused layout drift after a resize and artefacts while scrolling.
- **Cleanup survives an interrupted render.** Mute states, the time selection,
  render settings, project metadata, your item selection and any temporary files
  are restored even if the script is terminated mid-render, with each step
  guarded separately.

## What this release does not claim

- Preflight reports; it does not repair. Only the two reversible master-chain
  problems can be neutralised, and only if you ask for it.
- Loudness figures are ungated BS.1770 measurements. Dialog-gated
  specifications, Netflix among them, must be verified in a dedicated meter.
- Leq(m), used by trailer standards, is not measured.
- True-peak values reuse REAPER's own measurement within a small reporting
  grace.
- REAPER's render call is synchronous. During one very long file the progress
  display shows the stage and the batch position rather than a sample-accurate
  figure.

## Requirements

- REAPER 7 (64-bit)
- ReaImGui 0.10.0.5 or newer in the 0.10 API series
- SWS is optional; without it, loudness and bit depth read as "not measured"
- Windows, macOS, or Linux

## Upgrading

Install over the previous version and re-register only the packaged launcher.
Your settings and history are preserved, and every new feature is off by
default. There is no public 3.1.2, 3.1.3, 3.2.0 or 3.3.0 — 3.4.0 follows 3.1.1.

The release download contains the product, Inter font license, installation
instructions, a machine-readable manifest, and a separate SHA-256 checksum.
