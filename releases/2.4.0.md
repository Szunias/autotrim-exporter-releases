## AutoTrim Exporter 2.4.0

This product preview introduces a focused sound-design export workflow for REAPER. Version 2.4.0 brings selection, trimming, level preparation, naming, safe rendering, and result verification into one clear three-tab interface.

### Highlights

- Collect overlapping sound layers with **Select across tracks**.
- Automatically fit the arrange view to the selected result.
- Ignore unrelated long background items while retaining explicit anchors.
- Detect useful audio with independent start and tail thresholds.
- Preserve transients and reverb tails with configurable padding.
- Render one layered WAV or one WAV per selected item.
- Normalize using LUFS-I, RMS, Peak, or True Peak targets.
- Apply a true-peak ceiling during normalized renders.
- Step through imported naming lists for asset variations.
- Create incremented versions or explicitly replace an existing delivery.
- Validate temporary renders before committing final files.
- Review export history, skipped material, and diagnostics in the Results tab.

### Availability

This public preview contains product information and release notes only. No Lua source or distribution package is attached because the application source is maintained in a private repository. Licensed distribution packages will be announced separately.

### Requirements

- REAPER 7
- Windows, macOS, or Linux
- SWS Extension is optional
