# AutoTrim Exporter 3.5.1

Two fixes on top of 3.5.0, both from the first real session with queue mode.
Rendering engine 2.11.7. If you are upgrading from 3.4.4 or earlier, read the
[3.4.5 notes](3.4.5.md) too — they cover fixes that affect every delivery.

## Fixed: muting some layers no longer blocks the export

**If any track carrying your selected material was muted, the export was
refused outright — even when most of the selection was perfectly audible.**

Muting the variants you do not want is how a take gets chosen. Three muted
alternates among ten selected layers is ordinary work, not a broken session.
Preflight treated it as a hard blocker, so the export stopped with *"A track or
folder carrying selected material is muted"* and no way to proceed — and the
message never said how much material was actually affected.

Now the blocker fires only when **nothing audible is left**, which is the one
case where the delivered file could only be silence. Otherwise you get a warning
that counts exactly what stays out:

> 3 of 10 selected items will not reach the mix

The remaining material renders normally, and the export runs. Per-item delivery
was never affected — it bypasses the track path entirely.

## Fixed: a long take name no longer hides the queue controls

In a narrow window, a queue row's take name took as much width as it wanted,
pushing the reorder and remove buttons off the edge of the card. The only way to
reach them was to widen the whole window.

The three controls now reserve their width first, and the name is shortened with
an ellipsis to whatever is left — the full name is always in the row's tooltip.
The group number and the item count are never sacrificed, so a row stays
readable at any window size.

A queue holding a single group also previews `Name_01` now, instead of the
nonsensical `Name_01 … Name_01`.

## New: a hand-numbered name is flagged before it doubles up

Before queue mode, hand-numbering was the only way to number a batch — so a base
name ending in a number, like `Impact_1`, is exactly what you would type out of
habit. Queue numbering then lands next to it and you get `Impact_1_01.ogg`.

The panel now points this out while you are still building the queue, and shows
you the base name without the trailing number. It never changes the name for
you: `Layer_1` is a perfectly good base name, and guessing which is which would
be worse than simply saying it.

## Upgrading

Replace the installed scripts with the ones in this package. Your settings,
delivery profiles, name lists and export history are stored by REAPER and carry
over untouched.
