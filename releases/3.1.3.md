# AutoTrim Exporter 3.1.3

AutoTrim Exporter 3.1.3 is a delivery-quality release. It removes an audible
click at the end of merged exports, adds a delivery sample-rate override, and
brings a set of workflow controls to the interface. Rendering engine 2.8.3.

There is no 3.1.2; the numbering moves straight from 3.1.1 to 3.1.3.

## Fixed

- **No more click at the end of merged exports.** A real render fade-out is
  applied during final post-processing instead of only widening the render
  window, so an extended tail that has not fully decayed is faded rather than
  cut at the file boundary.
- **Clean endings in OGG and MP3.** Padded digital silence after the fade stops
  lossy transform blocks from decoding a stray non-zero tail sample.
- **No double fades in per-item export.** The item's own fade is left flat, so
  the render-level fade is applied once.
- **Vertical scrolling works in every REAPER language.** The stock scroll action
  is called by id instead of being looked up by name in the Action List.

## Added

- **Delivery sample rate.** Choose the sample rate of delivered files while
  analysis stays at project rate.
- **Safety ending control.** Replaces the bare "Extra tail" slider with duration
  presets for a deliberate, audible ending.
- **Name-list import with auto-advance.** Work through a list of names for
  variations and batches without retyping.
- **Loudness quick targets.** One-click common delivery targets alongside the
  existing LUFS-I, RMS, Peak and True Peak modes.
- **History filtering and copy-path** in the Results tab.
- **Native progress window.** Cancelling with `Esc` during a render no longer
  requires the js_ReaScriptAPI extension.
- **Tighter vertical framing.** The arrange view zooms in when the selected
  tracks have far more room than they need.

## Changed

- Refreshed colour palette and spacing across the interface.

## Requirements

- REAPER 7 (64-bit)
- ReaImGui 0.10.0.5 or newer in the 0.10 API series
- Windows, macOS, or Linux
- SWS Extension optional

## Upgrading from 3.1.1

Install over the previous version and re-register only the packaged launcher.
Settings are preserved; the old "Extra tail" value maps onto the new safety
ending control.

The release download contains the product, Inter font license, installation
instructions, a machine-readable manifest, and a separate SHA-256 checksum.
