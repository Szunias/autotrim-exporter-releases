# AutoTrim Exporter 3.4.3

AutoTrim Exporter 3.4.3 is the audited release of the 3.4 feature set. It
hardens project isolation, render transactions, filesystem delivery,
persistence, transport and packaging so a failed or interrupted export cannot
silently alter another project, overwrite source media, lose its Undo journal
or leave a half-published package. Rendering engine 2.11.4.

There is no public 3.1.2–3.4.2 — 3.4.3 follows 3.1.1 and carries everything from
those unpublished builds.

## Fixed in 3.4.3

- Per-item trimming no longer moves or resizes source items. Final renders use
  a time-selection window and native render fades, preserving takes, envelopes,
  stretch markers, source offsets and project timing.
- Every export remains bound to the exact source project tab. Render actions,
  preflight fixes, temporary tracks, selection restoration and cleanup cannot
  spill into another project after a tab switch.
- Combined renders retain upstream sidechains, downstream sends and folder
  routing while unrelated material stays isolated from the delivery.
- Cleanup is stateful, retryable and checked. Successful restore steps are not
  replayed over later user edits, while unfinished steps remain armed for the
  next export and script exit.
- New-version delivery fails closed on last-moment name collisions. Existing
  targets, project source media and byte-identical aliases are never silently
  replaced; retained temporary files are reported for recovery.
- A final render that unexpectedly becomes silent after active analysis is
  rejected before commit. Intentional silence remains available when trimming
  is disabled.
- Delivery Undo preserves work created after the export as an
  `.autotrim_undone_*` file before restoring the previous delivery.
- History and Undo finalize independently after a committed file, retry on exit
  and before the next export, and keep the Undo batch id armed until the write
  succeeds.
- A failed settings save keeps the dirty flag, retries, shows the error, and
  blocks a manual export until persistence succeeds.
- The parallel-render lock lasts 24 hours (REAPER blocks Lua during a long
  render, so a one-hour heartbeat timeout was unsafe). Clock skew keeps the lock
  active instead of releasing it.
- Audition will not steal foreign playback/recording; pause, seek-back and
  looping end an owned audition and restore the edit cursor.
- SWS loudness prefers `NF_AnalyzeTakeLoudness2` with a fallback to the older
  API.
- Audio-accessor cleanup errors are reported without hiding the analysis result.
- Name sanitization and the UI preview agree on trailing dots/spaces after the
  extension is stripped.
- A broken optional font falls back to the system font instead of blocking the
  UI.
- Mandatory Preflight, immutable queued settings, focus-safe shortcuts and
  top-level exception cleanup make the v3 interface fail closed around export
  state.
- The package builder uses a private workspace, detects source changes,
  serializes competing builds and rolls back partial publication. Repeated
  builds from the same snapshot are byte-identical within each supported
  PowerShell runtime.

## Requirements

- REAPER 7.37 or newer (64-bit)
- ReaImGui 0.10.0.5 or newer in the 0.10 API series
- SWS is optional; without it, loudness and bit depth read as "not measured"
- Windows, macOS, or Linux

## Upgrading

Install over the previous version and re-register only the packaged launcher.
Your settings and history are preserved.

The release download contains the product, Inter font license, installation
instructions, a machine-readable manifest, and a separate SHA-256 checksum.
