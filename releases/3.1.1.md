# AutoTrim Exporter 3.1.1

AutoTrim Exporter 3.1.1 is the first stable release of the Studio Dark workflow,
combining the production rendering engine with a focused ReaImGui interface.

## Highlights

- Separate Export, Trim & Tails, Loudness, and History workspaces.
- Vertical stack collection with complete horizontal and vertical framing.
- Protection against accidentally collecting unrelated long background items.
- Combined or per-item delivery in WAV, FLAC, OGG, or MP3.
- Adaptive Silence Map with independent start and tail thresholds.
- Pre-roll, controlled tail extension, and transactional auto-fade handling.
- LUFS-I, RMS, Peak, and True Peak targets with a true-peak ceiling.
- Safe incremental naming or deliberate replacement of existing deliveries.
- Verified temporary renders, rollback, bounded retries, and project-state restore.
- Real export history with Show in folder and Launch file actions.
- Cross-window render locking, visible job lifecycle, and safe cancellation points.

## Reliability work in this release

- Lossy codec padding is accepted without weakening incomplete-render checks.
- Stale media-item pointers are excluded before merged renders begin.
- Corrupt persisted settings are bounded to safe values.
- Temporary PCM sources and every render-state mutation have explicit cleanup.
- Vertical selection restores the original anchors and closes Undo on API errors.
- Filename previews and result counts now describe the actual engine behavior.

## Requirements

- REAPER 7 (64-bit)
- ReaImGui 0.10.0.5 or newer in the 0.10 API series
- Windows, macOS, or Linux
- SWS Extension optional

The release download contains the product, Inter font license, installation
instructions, a machine-readable manifest, and a separate SHA-256 checksum.
