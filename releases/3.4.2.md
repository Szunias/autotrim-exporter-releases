# AutoTrim Exporter 3.4.2

AutoTrim Exporter 3.4.2 is the audited build of the 3.4 line: preflight, undo,
boundary preview, a resizable window and a progress display that names the
stage, plus a pass over the places where a cancelled or failed export could
leave the project or a report in the wrong state. Rendering engine 2.11.3.

There is no public 3.1.2, 3.1.3, 3.2.0, 3.3.0 or 3.4.0 — 3.4.2 follows 3.1.1
and carries everything from those unpublished builds.

## New since 3.1.1

- **Preflight (key `6`).** Reports what a render will pass through before it
  runs, mode-aware between combined and per-item.
- **Opt-in one-click fix** for a muted master and a Bypass automation override,
  restored on every exit path.
- **Undo the last delivery**, off by default, with honest reporting when a
  backup is missing.
- **Boundary preview with audition** on Trim & fades.
- **Resizable window**, remembered size, and a progress display that names the
  stage (prepare, analyze, render, verify, finish).
- **Toggle action** — run again to close.
- UCS naming, embedded metadata, delivery profiles, WAV bit depth / RF64 /
  channel policy, and the delivery report from the unpublished 3.3.0 line.

## Fixed in 3.4.2

- Per-item exports restore fades, position, length and source offset on every
  exit path, including a silent skip and a cancelled render.
- No-trim mode keeps the item — and its fades — exactly as they sit in the
  project.
- Per-item undo is one batch for the whole export.
- WAV bit depth uses REAPER's mode codes; project/default depth keeps the
  project's full encoder profile when the format already matches.
- Built-in profiles never inject `nil` into loudness fields.
- Cancel after a file is committed still writes history, undo and the report.
- Reports are written atomically so a failed write cannot wipe the previous
  good report.
- Cleared metadata fields cannot leak a previous render's value into the next
  file.
- Audition will not steal a transport that is already playing or recording.
- Interface panels close correctly under ReaImGui when clipped out of view.

## Requirements

- REAPER 7 (64-bit)
- ReaImGui 0.10.0.5 or newer in the 0.10 API series
- SWS is optional; without it, loudness and bit depth read as "not measured"
- Windows, macOS, or Linux

## Upgrading

Install over the previous version and re-register only the packaged launcher.
Your settings and history are preserved, and every new feature is off by
default.

The release download contains the product, Inter font license, installation
instructions, a machine-readable manifest, and a separate SHA-256 checksum.
